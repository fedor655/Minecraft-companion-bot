# 🤖 Друг-бот для Minecraft (Java)

Бот-напарник, который выживает вместе с тобой. Ты пишешь команды в игровой чат —
он их выполняет. Состоит из двух частей:

- **`bot/`** — «тело» на Mineflayer (Node.js). Заходит в твой мир, ходит, прыгает,
  следует за тобой, видит, что вокруг. Открывает мост (WebSocket) для мозга.
- **`brain/`** — «мозг» на Python. Слушает чат и решает, что делать. Сейчас это
  простой мозг на правилах — фундамент для будущего умного мозга на базе ИИ (Claude).

```
Python (мозг)  ⇄  WebSocket  ⇄  Node/Mineflayer (тело)  ⇄  твой мир Minecraft
```

---

## 📦 Установка (один раз)

В этой папке открой терминал (PowerShell) и выполни:

```powershell
# Зависимости тела (Node.js)
cd bot
npm install
cd ..

# Зависимости мозга (Python)
cd brain
pip install -r requirements.txt
cd ..
```

## ▶️ Как запускать (каждый раз)

### 1. Открой мир для бота
1. Зайди в свой одиночный мир.
2. Поставь игру на паузу (Esc) → **«Открыть для сети»** (Open to LAN).
3. Режим — на твой вкус, **читы лучше включить** (пригодятся для команд позже).
4. Нажми «Открыть мир для сети». В чате появится:
   **`Локальная игра открыта на порту 54321`** — запомни этот **номер порта**.

> Порт каждый раз новый! Его нужно передавать боту.

### 2. Запусти тело бота
Дважды кликни **`start-bot.bat`** и допиши порт, ИЛИ в терминале:

```powershell
cd bot
node index.js --port 54321
```
(замени `54321` на свой порт из чата)

Бот зайдёт в мир — ты увидишь второго игрока «Druzhok».

### 3. Запусти мозг
Дважды кликни **`start-brain.bat`**, ИЛИ:

```powershell
cd brain
python brain.py
```

### 4. Командуй в игровом чате!
Напиши в чате Minecraft:

| Что написать | Что сделает бот |
|---|---|
| `привет` | поздоровается и покажет список команд |
| `ко мне` | подойдёт к тебе |
| `за мной` | будет ходить за тобой |
| `стоп` | остановится |
| `где ты` | назовёт здоровье, еду и координаты |
| `прыгни` | подпрыгнет |
| `что вокруг` | расскажет, кого видит рядом |

## ⚙️ Настройка

Файл **`bot/config.json`**:

```json
{
  "host": "localhost",     // обычно так и оставляй
  "port": 25565,           // порт мира (или передавай через --port)
  "username": "Druzhok",   // имя бота в игре
  "version": "auto",       // авто-определение версии Minecraft
  "bridgePort": 3000       // порт моста между телом и мозгом
}
```

Если меняешь `username`, поменяй и `BOT_NAME` в начале `brain/brain.py`.

## 🧠 Что дальше

Сейчас бот понимает простые команды. Следующие шаги, чтобы сделать его умным:

1. **Навыки выживания** — рубить дерево, копать, крафтить, есть, убегать от мобов.
2. **Умный мозг на Claude** — бот будет понимать команды на любом языке
   («собери дерева на дом») и сам планировать действия.
3. **Авто-режим** — бот сам выживает рядом: ночью прячется, голодный — ест,
   видит зомби — бежит к тебе.

---

## ❓ Если что-то не так

- **Бот не заходит** → проверь, что мир «Открыт для сети» и порт правильный (`--port`).
- **Мозг пишет «Нет связи с мостом»** → сначала запусти тело (`bot`), потом мозг.
- **Бот заходит и сразу вылетает** → возможно, версия. Укажи её в `config.json`,
  например `"version": "1.20.4"`.
